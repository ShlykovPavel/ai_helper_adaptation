# «Ты ещё тут?» — черновой цикл Astral

Пробный покадровый цикл: **32 уникальных рисунка imagegen, 4 секунды, 8 новых поз/с**.
Плеер показывает 96 тактов при 24 fps с удержанием рисунков. Интерполяции нет.
Все 32 рисунка действительно используются; это не 96 новых рисунков.
Канонический мастер и runtime не изменены. Цикл ещё не финальный и не встроен в приложение.

Открыть `index.html` непосредственно в браузере или запустить из корня проекта:

```sh
python3 -m http.server 8773 --bind 127.0.0.1 --directory design/mascot/astral-v2/animations/are-you-still-here
```

Адрес: http://127.0.0.1:8773/. При занятом порте выбрать свободный, не останавливая чужой процесс.
В плеере есть пауза, шаг назад/вперёд по тактам, ползунок, скорость 0.25/0.5/1×,
тёмный и светлый фон, уменьшенные варианты 26/64 px.

Файлы:

- `part-1-generated.png`, `part-2-generated.png` — нетронутые результаты imagegen, 16 поз каждый, 1254×1254 RGBA.
- `frames/frame-000.png` … `frame-031.png` — 32 рисунка 384×384 RGBA, порядок по строкам первого листа, затем второго.
- `atlas.png` — 4 колонки × 8 рядов, 1536×3072 px; `atlas.json` — прямоугольники, SHA-256, исходные кропы, переносы и точные 96 тактов.
- `preview.webp` — прозрачное анимированное превью; `preview-light.gif` — GIF со светлой подложкой. Оба по 4 секунды.
- `key-poses-generated.png` — ранние 8 ключевых поз, не дополнительные кадры таймлайна.
- `report.md`, `generation.json`, `verification.json` — происхождение, промпты, результаты и ограничения.
- `browser-blink-review.png` — снимок проверки плеера в браузере.

Для пересборки нужна установленная библиотека **Pillow**. В этой сессии использован Python3 с Pillow 12.2.0.
Скрипт не вызывает imagegen повторно, а нарезает сохранённые листы и упаковывает результаты:

```sh
python3 scripts/pack-astral-idle.py
python3 scripts/pack-astral-idle.py --check
```

Рисунок 0 используется 4 такта (3 в начале + 1 в конце), рисунок 31 — 2 такта,
остальные — по 3. Последний такт повторяет точный рисунок начала, поэтому WebP/GIF имеют
33 последовательных блока при 32 уникальных рисунках. Моргание: рисунок 22 (23-й при счёте с 1), 2.750–2.875 с, 125 мс.

Из-за неровного расположения поз в сгенерированной сетке нарезка ищет прозрачные промежутки.
Затем каждый целый рисунок только переносится на общий холст и масштабируется одинаково вместе со своей ячейкой.
Ни веки, ни лапки, ни тело не рисуются и не деформируются кодом. Подъём 10 px на холсте384 — заданный путь центров при упаковке;
его сопровождают реально сгенерированные изменения лапок/волн/силуэта.

Известные ограничения: 8 новых поз/с дают заметную ступенчатость; наклон во второй половине слабый;
материал, глаза и размеры немного меняются между рисунками. После выравнивания центров на стыке31→0
сохранился скачок ширины 288→264 px и высоты292→281 px. Стык позиции замкнут, художественная бесшовность не достигнута.
Размер384 — экспорт после общего равномерного ресемплинга ячейки350px, а не384px исходной детализации.
Для native-загрузчика этот атлас пока не является готовым контрактом ресурсов.
