# Astral — приветствие из двух PNG-слоёв

Проверка продолжена 19 октября 2026. Пользователь выбрал раздельные PNG-слои
после того, как цельные покадровые листы меняли тело и давали рывки лапки.

[Плеер](index.html): **4 секунды, три взмаха, один проход, без звука**.
Тело — один неизменяемый PNG. Лапка — второй PNG, поворачиваемый от одной
фиксированной точки на плече. Размеры и форма обеих картинок не меняются
между фазами. Движение вычисляется непрерывно; это **два исходных изображения,
а не 96 заново нарисованных кадров**. Моргание пока отсутствует.

## Сценка

| Время | Действие |
|---|---|
| 0–0,4 с | Мягкое появление прозрачностью, геометрия тела неподвижна |
| 0,65–1,2 с | Поднимает левую лапку |
| 1,2–2,5 с | Три взмаха с уменьшающейся амплитудой |
| 2,5–3,45 с | Плавно опускает лапку |
| 3,45–4 с | Спокойная поза; в 4 с — остановка |

Есть пауза, повтор с начала, перемотка по времени, скорость 1×/0,5×/0,25×,
четыре подложки, слоты 26/64 CSS px и сравнение с B/D.

## Изображения и устройство движения

Сабагент создал два изображения через built-in imagegen:
[тело без левой лапки](assets/body-generated.png) и
[отдельную левую лапку](assets/paw-generated.png), оба 1254×1254 RGBA.
Точные [промпт тела](assets/body-prompt.txt), [промпт лапки](assets/paw-prompt.txt),
роли/порядок референсов, SHA и ограничения — в [assets/generation.json](assets/generation.json).
Тело получено редактированием B0 с удалением только левой лапки; правая,
два белых глаза и три нижние волны сохранены. Это отдельная проба, не замена
канонического мастера.

Raw PNG не перерисовываются кодом и не очищаются. [rig.json](rig.json)
описывает прямоугольники области рисунка по alpha≥8; Canvas берёт их из
оригиналов. Прозрачные мелкие RGB-speckles снаружи рисунков исключены областью
просмотра, исходные файлы сохранены побайтово. Масштаб каждого слоя постоянен
на протяжении клипа. Точка лапки в raw PNG — (690,1095), её мировая позиция
всегда совпадает с одной точкой плеча. Никаких новых фаз рисунка код не создаёт.

[motion.mjs](motion.mjs) управляет только углом и общей прозрачностью:
подъём/опускание используют плавную кривую с нулевой скоростью на концах,
каждый взмах — полная дуга туда и обратно. Корпус не наклоняется, не прыгает,
не меняет пропорции. Плеер использует requestAnimationFrame и останавливается
при скрытии страницы. Это описание исходного HTML-прототипа; обновление native — ниже.

## Оставшаяся доводка

- У плеча заметен светлый контур соединения: лапка ещё читается как отдельная
  деталь. Нужна художественная доводка стыка, особенно на светлой подложке.
- Лапка поворачивается целиком; мягкий изгиб и самостоятельная смена бликов
  не нарисованы. Художественная приёмка пользователем ещё открыта.
- Моргание отсутствует. Native-подключение выполнено отдельно, см. ниже.

Следующий шаг — оценка жеста в проигрывании, затем смягчение стыка и моргание.
Не возвращаться к генерации всего тела на каждый кадр без отдельной причины.

## Native macOS — 19 октября 2026

Пользователь принял пробу и поручил внедрение. В основной рабочей папке
`LaunchGreetingView` выбирает нативное приветствие для Astral. Два raw PNG
и исходный `rig.json` скопированы побайтово в
`NotchBuddy/Resources/Mascots/AstralGreeting`; метаданные исходного прототипа
(`runtimeIntegrated: false`) сохранены как свидетельство того этапа.
`AstralGreetingAnimation.swift` переносит движение и геометрию без новых рисунков.
Загрузка/обрезка PNG выполняется один раз, `TimelineView` останавливается
после 4 с. Завершение отправляется один раз; исчезновение и прерывание его
отменяют. Существующие правила hover/сворачивания остаются в IslandStateMachine.
При выборе Mochi показывается его прежняя сценка; резервная сценка при
недоступности ресурсов Astral запускается без музыки.

`bash scripts/test-astral-greeting.sh` прошёл: 25 экспортированных поз исходного
браузерного плеера совпадают по углу и прозрачности, проверены однократное
завершение/прерывание, загрузка ресурсов и реальное рисование PNG через CoreGraphics.
Общий mascot-набор пока останавливается на старом `test-facade.sh`: общий
`FlowHubTestStubs.swift` ссылается на не включённые в эту команду `AskQuestion`
и `TelegramEvent`. Новый тест и этапы geometry/compact/expanded/sprite проходят.
Полная Debug-сборка Xcode завершилась `BUILD SUCCEEDED`. PNG и rig в bundle
побайтово совпадают с источниками. Готовая сборка:
