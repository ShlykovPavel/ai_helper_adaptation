# Astral — отдельная проба одного взмаха

По замечанию пользователя о «глючащей лапке» сабагент создал новый лист A
и одну точечную коррекцию B через built-in imagegen. **В просмотре B, это
проба движения с оставшимися дефектами. Художественная приёмка открыта.**

Пользователь по скриншоту подтвердил направление поднятой лапки:
«это уже похоже на то что нужно». Это подтверждение позы, а не приёмка
плавности в проигрывании. Следующий шаг — стабильное крепление и мягкое опускание.

[Открыть плеер](index.html): 16 разных рисунков, **12 новых рисунков/с,
1,333 секунды**, один проход, без звука. Это короткая проверка жеста,
не готовая сценка 96 / 4 с и не финальные 24 новых рисунка/с. Есть повтор,
покадровый шаг, перемотка, замедление, фоны и слоты 26/64 CSS px.

Лапка теперь отчётливее поднимается рядом с глазами. В A кадр 6 ложился
горизонтально и 7 снова вставал; B устраняет этот резкий переворот.
Положение корпуса по высоте стабильнее: максимальное изменение высоты
силуэта между соседями0,63%. Это не измерение плавности самой лапки.

В B ещё смещается место крепления лапки к щеке, силуэт недостаточно
отделён от головы, 10→11 слегка меняет наклон,11→12 слишком резко опускает
лапку. Небольшие изменения тела/света также остаются. Кандидат B не принят
как финальное махание. Подробная оценка root — в [review.json](review.json).

## Файлы и проверка

- [wave-source.png](wave-source.png) — выбранный для просмотра B, 1254×1254 RGBA, 4×4.
- [Кандидат A](wave-candidate-a.png), [кандидат B](wave-candidate-b.png) — сохранены отдельно.
- [Промпт B](prompt.txt), [промпт A](prompt-candidate-a.txt).
- [generation.json](generation.json) — точные промпты/референсы/SHA и оценка сабагента
  на момент генерации; [архив A](generation-candidate-a.json).
- [atlas.json](atlas.json) — нарезка/размещение/масштаб/хеши каждого кадра.
- [verification.json](verification.json) — техническая проверка 16 рисунков;
  успешная проверка не означает художественную приёмку.

Упаковка из корня репозитория:

```sh
python3 scripts/pack-astral-wave-probe.py
python3 scripts/pack-astral-wave-probe.py --check
```

Нарезка по прозрачным коридорам, единый масштаб всех ячеек, затем перенос
целого рисунка: центр верхнего купола по X, верх силуэта по Y. Код не
деформирует лапку/тело, не смешивает и не генерирует промежуточные кадры.
Исходная мягкая альфа сохранена; max alpha границы 2, видимый силуэт не обрезан.
Все 16 PNG восстанавливаются из источника точно и совпадают с атласом;
проверены 9 записей происхождения. Отдельный `--check` не изменил SHA/mtime
файлов. Синтаксис JavaScript плеера проверен через Node.

В браузере проверены один проход/стоп на 16, перемотка фаз 7/11/12,
замедление, тёмная/светлая подложки и размеры 26/64 px. В 64 px поднятие
различимо; в 26 px форма менее читаема, особенно на светлом фоне.
[Снимок B](browser-probe-b.png).

Прежний [клип 96 / 4 с](../index.html), мастера и приложение сохранены.
Новая проба не интегрирована в полную сценку или native.
