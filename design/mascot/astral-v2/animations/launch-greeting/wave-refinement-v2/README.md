# Astral — продолжение пробы взмаха, C/D

**В плеере D: спуск стал последовательнее, но замена B не принята.**
16 разных рисунков, 12 новых рисунков/с, 1,333 с, один проход без звука.
Это не полный клип 96/4 с и не финальные 24 уникальных рисунка/с.

[Открыть D](index.html) · [Сравнить с B](../wave-redraw-probe/index.html) ·
[Рецензия root](review.json).

C был одним EDIT B. Скачок 11→12 остался: по грубой диагностике левого
контура 38,23 px против 37,52 px у B. [C отклонён](review-candidate-c.json).
D создан одним новым вызовом imagegen по отдельным опорным позам C:
наружная 7, поднятая 10, спокойная 15. Весь плохой лист референсом не был.

В D движение вниз начинается уже в 11, фазы 10–14 идут последовательно
без лишнего обратного подъёма. Независимый просмотр подтвердил улучшение.
Но ритм неровный: 11→12 сравнительно мал, 14→15 заметно меняет гладкий
овал в согнутую лапку. Крепление всё ещё выглядит как овал у щеки.
Корпус стал шире: финальное отношение ширины силуэта к высоте D=0,9153,
B=0,8313 — разница около 10,1%. Не сужать это кодом и не объявлять D
в целом более удачной заменой B. B остаётся ориентиром внешности,
одобренным пользователем по скриншоту; движение целиком ещё не принято.

Следующий шаг: стабильное крепление, пропорции B и промежуточный сгиб 14→15.
До этого не переносить D в полный клип и не подключать к runtime.

Диагностика — средняя Y самой левой полосы alpha32 шириной 4 px, а не точный
трекинг лапки/сустава. Разные поля/масштабы B/D не позволяют оценить всё
качество движения сравнением одного числа.

D получен 1266×1242 RGBA вместо запрошенных 1254×1254; сырые пиксели сохранены.
Нарезка адаптируется по прозрачным коридорам, файл не растягивался в квадрат.
Все 16 ячеек имеют одну основу extent=341 source px и один масштаб. В основу
включены 16 px дополнительного прозрачного поля для всех рисунков: без него
выравнивание купола обрезало бы 4 видимых px крайней лапки. Эта обрезка была
отвергнута. Код только режет, добавляет поля, равномерно масштабирует и
переносит целые рисунки; не деформирует тело/лапки и не создаёт промежуточных.
