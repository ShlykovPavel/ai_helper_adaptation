# Astral Morph — заготовки смены формы

Для агента с чистым контекстом: [передача работы](../../../../docs/MASCOT_HANDOFF.md)
и [действующая дизайн-спецификация](../../../../docs/MASCOT_DESIGN_SPEC.md).

Три статичные ключевые формы сохранённого Astral v2: шар, мягкий куб и огонёк.
Материал и лицо взяты из утверждённого призрака. Сам призрак и его 245 экспортов
не изменены. Постоянного ядра нет: знак агента добавляется отдельным слоем ниже глаз.

Шар, куб, огонёк A и логотипы утверждены. Основной огонёк —
[A «Цельное пламя»](wisp-candidates/a-candle.png); он экспортирован в те же
64, 240, 480, 720 и 960 px, что шар и куб. Все три примера огонька с логотипами
пересобраны на его основе. Предыдущий мастер сохранён отдельно в
`wisp-candidates/previous-wisp.png`, остальные кандидаты —
в [сравнении A / B / C](wisp-candidates/index.html).
Статусы записаны в [review.json](review.json).

## Что готово

- `masters/`: три исходных прозрачных PNG 1254×1254 из встроенного imagegen.
- `frames/`: каждая форма в 64, 240, 480, 720 и 960 px; единый квадратный холст.
- `logos/`: отдельные SVG OpenAI, Claude и Gemini с указанием источников ниже.
- `examples/`: девять самостоятельных SVG — три формы × три логотипа.
  Внутри каждого SVG встроены PNG тела и SVG логотипа, внешние файлы не нужны.
- [index.html](index.html): просмотр форм и сочетаний, переключение знака,
  примерка своего SVG/PNG локально через браузер.
- [animation-blueprint.json](animation-blueprint.json): предполагаемые состояния,
  координаты логотипа и черновые циклы для будущей покадровой генерации.
- [generation.json](generation.json): промпты, источники и SHA-256 исходных PNG.

Это ключевые позы и статичные композиции. Промежуточные кадры превращений,
спрайт-листы и нативное подключение в приложение пока не сделаны.

## Предлагаемые состояния

| Событие | Форма | Будущее поведение |
|---|---|---|
| Idle | Исходный призрак без знака | Парение, моргание, смешные наклоны и редкие короткие превращения |
| Работа | Огонёк A | Покачивание язычков пламени, сосредоточенный взгляд |
| Агент закончил | Шар со знаком агента | Мягкое округление, довольный подскок |
| Вопрос / подтверждение | Куб со знаком агента | Любопытный наклон к пользователю и ожидание |
| Возврат к idle | Исходный призрак | Исчезновение знака, возвращение лапок и нижних волн |

Форма обозначает состояние, логотип — агента. Один и тот же агент может быть
и шаром, и кубом; он не закреплён за одной формой.

## Как заменить логотип

Для быстрой примерки откройте `index.html` и выберите «Свой логотип SVG / PNG».
Файл используется через локальный browser object URL и никуда не отправляется.

Для сохранения трёх самостоятельных SVG в репозитории:

```sh
python3 scripts/compose-astral-logo.py --logo /path/to/company.svg --name company
```

Результат: `examples/astral-orb-company.svg`, `astral-cube-company.svg`,
`astral-wisp-company.svg`. Вместо SVG можно передать прозрачный PNG.
Чтобы сохранить в другую папку, добавьте `--output /path/to/folder`.
Команда без аргументов пересобирает девять примеров для OpenAI, Claude и Gemini.
Скрипт не генерирует нового персонажа и не меняет исходные PNG.

У логотипа сохраняются пропорции (`contain`). Желательно использовать квадратный
знак с прозрачным фоном и небольшими собственными полями. Длинное название
компании лучше выводить рядом с маскотом, а внутри оставить её символ.

## Подготовка к анимации

Канонический холст — 240×240. Экспорты 480/720/960 позволяют работать на
плотных экранах. Текущие формы сохраняют композицию генерации, без подрезания
силуэта; точное выравнивание глаз и размера тела между кадрами ещё предстоит
сделать при создании настоящего цикла.

Координаты в blueprint нормализованы от 0 до 1 относительно квадратного холста.
У каждой формы есть центр и размер области знака. Это положение только
текущей ключевой позы, не постоянная координата для всех будущих кадров.
Для каждого кадра с движением тела нужно сохранить позицию, угол,
прозрачность и при необходимости маску перекрытия знака.

Во время самого превращения знак скрыт. Он проявляется после стабилизации
шара или куба; перед возвратом в призрака исчезает. Поэтому не требуется
рисовать отдельный цикл превращения для каждого агента или каждой компании.

На размере меньше 48 логических пикселей сложный логотип внутри может потерять
читаемость. Для чёлки и мини-агентов используйте внешний цветной бейдж и подпись;
внутренний знак раскрывается вместе с увеличением персонажа.

`planned_clips` описывает предполагаемые движения и ориентировочное число кадров.
Эти кадры ещё не сгенерированы. CSS-переключение картинок не заменяет покадровую
анимацию жидкого превращения.

Нынешний native mapper сводит некоторые события в idle/approval. При будущем
подключении нужно сохранить различие finished/question/permission и не
определять причину обращения только по итоговому action.

## Источники знаков

- OpenAI и Claude: [Lobe Icons](https://github.com/lobehub/lobe-icons), исходные
  SVG из `packages/static-svg/icons/openai.svg` и `claude-color.svg`.
  MIT-текст сохранён в `logos/LobeHub-LICENSE.txt`.
  Для OpenAI `currentColor` в композиции разрешается в белый; контуры не меняются.
- Gemini: SVG `gemini_sparkle_aurora_33f86dc0c0257da337c63.svg` с gstatic,
  указанный в HTML [Gemini](https://gemini.google.com/).
- Конкретные URL записаны в `generation.json`. Права на знаки остаются у их владельцев.
