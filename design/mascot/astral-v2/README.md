# Astral Morph v2 — утверждённый маскот без ядра

Для агента с чистым контекстом: [передача работы](../../../docs/MASCOT_HANDOFF.md)
и [действующая дизайн-спецификация](../../../docs/MASCOT_DESIGN_SPEC.md).

Статичный фронтальный idle-образ. В этом наборе нет новых поз, эмоций или кадров анимации.
Изображения сохранены в репозитории; работающие рендеры приложения не менялись.

Новые формы (шар, куб, огонёк), сменные логотипы GPT/OpenAI, Claude и Gemini
и план будущих переходов находятся в отдельном [morph-kit](morph-kit/README.md).

## Файлы

- `astral-idle-master.png` — оригинал генерации 1254×1254, RGBA; сохранён без изменений.
- `astral-idle-normalized.png` — тот же рисунок с квадратными прозрачными полями 1016×1016.
- `png/` — **49 логических размеров × 5 плотностей = 245 прозрачных PNG**.
- [sizes.html](sizes.html) — каталог размеров с предпросмотром и ссылками на каждый файл.
- [sizes.json](sizes.json) — размеры, плотности, контрольные суммы и соответствие местам в исходном коде.
- [generation.json](generation.json) — исходные промпты встроенного imagegen и сведения о генерации.
- `current-*.png` — сравнение с текущими Swift-рендерами, не снимки работающего приложения.
- `preview-*.jpg` — снимки [статичной примерки](../../prototype/mascot-generated-v2.html).

## Размеры и плотности

Размеры квадратного слота в pt / CSS px / dp:

`12, 13, 16, 18, 20, 22, 24, 26, 28, 30, 32, 34, 36, 40, 42, 44, 46, 48, 50, 52, 54, 56, 58, 60, 62, 64, 66, 70, 72, 74, 76, 77, 84, 87, 88, 94, 96, 97, 104, 108, 110, 112, 120, 132, 140, 150, 160, 170, 240`.

Для каждого размера есть 1×, 1.5×, 2×, 3× и 4×:

- `png/astral-idle-26.png` — 26×26 px.
- `png/astral-idle-26@2x.png` — 52×52 px для слота 26 pt.
- `png/astral-idle-26@3x.png` — 78×78 px для того же слота.
- Apple: 1× / 2× / 3×. Web / Windows: версия под плотность экрана.
- Android: mdpi / hdpi / xhdpi / xxhdpi / xxxhdpi соответствуют 1× / 1.5× / 2× / 3× / 4×.
- При дробном числе пикселей сторона округляется вверх: 13 dp × 1.5 = 20 px.

Включены мини-агенты, чёлка, пилюли, размеры острова, Hub, настольная панель,
iPhone, Live Activity и виджеты, Android-экраны и виджеты. В `sizes.json` отделены
размеры слота, внутреннего рисунка после padding и округлённые размеры холста
`diameter / 0.6`. 160 — объявленный предел hero-варианта; 240 — формат будущего кадра.

## Поля и использование

Все экспорты получены из одного исходника. Нормализация обрезает только поля:
прямоугольник `x=119, y=133, width=1016, height=1016` в координатах оригинала.
Заметный силуэт занимает около 92% высоты; сверху и снизу остаётся прозрачный запас.
Рисунок, цвета и альфа-канал внутри обрезки не перерисовываются.
Оригинальный master остаётся неизменным.

Используйте сохранение пропорций (`aspect fit` / `object-fit: contain`).
Экспорт уже нормализован: увеличивать его на 132%, как исходный master
в старой HTML-примерке, не нужно. Отступ карточки (`padding`) применяется снаружи.

Для плавно меняющегося размера или произвольной ширины виджета берите ближайший
больший PNG; крайний вариант — `astral-idle-240@4x.png` (960×960), без увеличения исходника.
Для полностью скрытого маскота с opacity=0 отдельный файл не нужен.

Это полноцветный набор. Монохромный вариант для tinted / accented виджетов iOS
требует отдельной подготовки: простой размерный экспорт не решает отображение глаз.
Иконки приложения и значки уведомлений здесь не заменяются.

`astral-idle-240.png` — один кадр. Не переименовывайте его в `astral_idle.png`:
нынешний загрузчик ожидает под этим именем полосу из 20 кадров.

## Повторный экспорт и проверка

На macOS, из любой папки:

```sh
python3 /path/to/repo/scripts/export-astral-mascot.py
python3 /path/to/repo/scripts/export-astral-mascot.py --check
```

Экспорт выполняет системная утилита `sips`, без новой AI-генерации.
Проверка сверяет размеры, RGBA8, PNG CRC, распаковку данных, контрольные суммы
всех файлов и наличие указанных исходников. После замены master нужно повторить
экспорт; случайное изменение master обнаруживается по SHA-256.
