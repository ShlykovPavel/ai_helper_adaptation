# Astral Launch Greeting Implementation Plan

> **For agentic workers:** Work is explicitly authorized by the user, including
> subagent execution. Art generation and packaging have separate ownership;
> the main agent reviews their concrete results before continuing generation.

**Goal:** Спланировать беззвучное приветствие Astral на 4 секунды и начать
создание реальных кадров с проверяемым однократным превью.

**Architecture:** Built-in imagegen создаёт рисунки с утверждённым PNG как
эталоном. Python/Pillow воспроизводимо упаковывает готовую последовательность;
HTML показывает её фактическую длительность. Runtime приложения не меняется.

**Tech Stack:** Built-in imagegen, Python 3/Pillow, PNG/JSON, HTML/Canvas.

**Spec:** [Полная сценка и критерии](../../../design/mascot/astral-v2/animations/launch-greeting/plan.md).

## Global Constraints

- Без музыки, звуков, новых зависимостей приложения и внешней публикации.
- Канонический Astral, прежние idle v1/v2 и runtime сохраняются.
- Цель: 96 настоящих разных рисунков / 4 с / 24 рисунка в секунду.
- Первый этап может содержать только начало; оно маркируется частичным.
- Только встроенная генерация изображений; точные промпты/референсы/SHA сохраняются.
- Не подменять промежуточные рисунки деформацией, смешиванием или повтором.

## Review Focus

- Поднятая лапка: остаётся маленькой и соединённой с телом, жест читается.
- Между листами: не меняются камера, лицо, свет и общий масштаб.
- Прозрачные поля: лапка, волны и края тела не обрезаются при нарезке.
- Неполный фрагмент: проигрыватель честно показывает N/96 и N/24 секунды.
- Завершение: один проход до последнего рисунка, без повторения приветствия.

## Продолжение после первого фрагмента

Следующие листы создаются по одному: 16–31, 32–47, 48–63, 64–79, 80–95.
Каждый получает мастер и реальную конечную позу предыдущего листа; после
упаковки проверяются все соседние переходы. Полный клип получает художественную
приёмку отдельно. Native-внедрение требует собственного согласованного
контракта загрузки, проверки запуска/прерывания/паузы и переключения в idle.
